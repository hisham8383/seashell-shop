# Nacré — Seashell Hangings & Chandeliers

A dreamy, bohemian-luxury one-page website for a shop specializing in seashell hangings and
shell chandelier lamps. Brown, pink, and gold palette, soft imaginative styling, radiant
shell imagery.

## Structure

- `index.html` — single-page site (hero, story, collections, atmosphere quote, gallery, visit, contact)
- `styles.css` — all styling (fonts: Cormorant Garamond, Marcellus, Jost via Google Fonts)
- `script.js` — mobile nav toggle, contact form handling, scroll-reveal animations
- `assets/images/` — reference shell/water photography used across the site

## Running locally

No build step — it's static HTML/CSS/JS. Open `index.html` directly in a browser, or serve it:

```
cd seashell-shop
python3 -m http.server 8080
```

Then visit http://localhost:8080
